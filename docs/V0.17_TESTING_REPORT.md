## Bugs found and fixed during testing

### 1. JSON serialization after date cleaning
Cleaning a dataset containing invalid/missing dates could return HTTP 500 because pandas `NaT` values were left in the preview response.

**Fix:** cleaning previews now convert pandas missing values to `null` and pandas timestamps to ISO strings.

### 2. Histogram endpoint error
The histogram chart endpoint attempted to call `value_counts()` on the tuple returned by `pd.cut(..., retbins=True)`.

**Fix:** histogram generation now uses the categorical interval result directly.

### 3. Unsupported cleaned export format
An unsupported format could previously fall through to CSV.

**Fix:** only `csv` and `xlsx` are accepted; unsupported formats return HTTP 400.
