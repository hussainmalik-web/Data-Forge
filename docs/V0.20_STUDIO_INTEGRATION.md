# V0.20 — Studio UI Integration

## Integration rule

The existing Data Forge backend remains the source of truth for data processing. The Studio AI project is used as the presentation layer only.

## Preserved workflow

1. Upload CSV/XLSX
2. Dataset preview
3. Dataset profile
4. Data quality checks
5. Quality score
6. Cleaning operation selection
7. Cleaning preview
8. User-approved cleaning apply
9. Before/after metrics
10. Cleaning audit log
11. Data exploration
12. Visualization recommendations and chart data
13. Automatic dashboard
14. CSV/XLSX export
15. Quality report export

## Cleaning operations exposed by the UI

- Remove duplicate rows
- Remove completely empty rows
- Remove completely empty columns
- Remove rows containing missing values
- Fill missing numeric values: median, mean, zero
- Fill missing categorical values: Unknown, mode, forward fill
- Trim whitespace
- Standardize text: lowercase, Title Case, UPPERCASE
- Parse date columns
- Convert types: numeric, string, date
- Rename columns
- Remove selected columns

## Safety rules

- Preview does not modify the original dataset.
- Apply creates a separate cleaned dataset.
- Export does not modify the source dataset.
- UI copy must not present invented business metrics as real data.
- API adapters normalize response shapes only; they do not fabricate analytical values.
