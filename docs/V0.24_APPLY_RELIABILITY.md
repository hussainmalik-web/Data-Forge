# Data Forge v0.24 — Apply Reliability

This release hardens the cleaning commit workflow.

- The exact staged cleaning operations are frozen at click time.
- Apply does not depend on a previous Preview action.
- The commit is treated separately from refreshing the workspace.
- A successful backend commit remains a success even if the post-commit UI refresh fails.
- Apply buttons prevent accidental form submission.
- The cleaning action bar exposes commit progress and errors without requiring the user to scroll to the top of the page.
- The original dataset remains unchanged; Apply creates a new cleaned dataset.
