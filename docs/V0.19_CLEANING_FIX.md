# Data Forge v0.19 — Cleaning Fix

## Problem addressed

The earlier cleaning workflow could appear ineffective because the UI only displayed before/after summary metrics and did not show the resulting cleaned rows. In addition, numeric values represented as text and common missing-value tokens could be missed by the numeric cleaning logic.

## Changes

### Backend
- Numeric missing-value filling now detects:
  - true numeric pandas columns
  - numeric-looking text columns
  - common missing tokens such as blank, NA, N/A, null, none, nan, -, --, and ?
- Numeric filling supports median and mean.
- Categorical filling supports a configurable replacement value.
- Common missing text is normalized for row/column removal.
- Whitespace-only text can become missing after trimming.
- Date parsing can use selected columns or detected date-like column names.
- Type conversion supports numeric, string, and date.
- Rename and remove-column operations validate inputs.
- Cleaning logs include row/column/missing-cell impact.

### Frontend
- Added cleaning controls for all V1 backend operations.
- Added operation-specific configuration fields.
- Added a real cleaned-data preview table using the backend `preview_rows`.
- Preserved approval workflow: Preview Changes first, then Apply Changes.
- Original uploaded data remains unchanged.
- Cleaned CSV/XLSX exports remain available after applying changes.
