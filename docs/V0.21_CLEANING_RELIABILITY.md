# v0.21 — Cleaning Reliability Fixes

## Problem addressed
The Studio-integrated cleaning UI could stage unintended missing-value operations from default settings, and the Apply Changes action could appear unavailable or require a page reload in some UI states.

## Fixes
- Missing numeric/categorical operations are staged only when target columns are explicitly selected.
- Numeric fill supports median, mean, and zero fill.
- Categorical fill supports Unknown, mode, forward fill, and a custom replacement value.
- Apply Changes validates that at least one real operation is staged.
- Apply Changes does not depend on the preview state.
- Dataset refresh after apply no longer replaces the workspace with a loading screen.
- Successful applied results remain visible in Clean with before/after metrics and the cleaned dataset ID.
- The original uploaded dataset remains unchanged.

## Validation
- Full backend test suite: 15 passed.
- Direct service test covered all supported cleaning operation types and a combined pipeline.
